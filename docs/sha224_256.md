# US Secure Hash Algorithms

[RFC6234](https://datatracker.ietf.org/doc/html/rfc6234)

* Throughout this document, the "big-endian" convention is used when
  expressing both 32-bit and 64-bit words.
* block = 512-bit or 1024-bit string. A block (e.g., B) may be
  represented as a sequence of 32-bit or 64-bit words
* The right shift operation SHR^n(x), where x is a w-bit word and n
  is an integer with 0 <= n < w, is defined by
  `SHR^n(x) = x>>n`
* The rotate right (circular right shift) operation ROTR^n(x), where
  x is a w-bit word and n is an integer with 0 <= n < w, is defined
  by `ROTR^n(x) = (x>>n) OR (x<<(w-n))`
* The rotate left (circular left shift) operation ROTL^n(x), where x
  is a w-bit word and n is an integer with 0 <= n < w, is defined by
  `ROTL^n(X) = (x<<n) OR (x>>(w-n))`

## Message Padding and Parsing

* The length of the message is the number of bits
* a "1" followed by m "0"s followed by a 64-bit or 128-bit
  integer are appended to the end of the message to produce a padded
  message of length 512*n or 1024*n.
* The appended integer is the
  length of the original message.

## Functions and Constants Used

SHA-224 and SHA-256 use six logical functions, where each function
operates on 32-bit words, which are represented as x, y, and z. The
result of each function is a new 32-bit word.

```
CH( x, y, z) = (x AND y) XOR ( (NOT x) AND z)

MAJ( x, y, z) = (x AND y) XOR (x AND z) XOR (y AND z)

BSIG0(x) = ROTR^2(x) XOR ROTR^13(x) XOR ROTR^22(x)

BSIG1(x) = ROTR^6(x) XOR ROTR^11(x) XOR ROTR^25(x)

SSIG0(x) = ROTR^7(x) XOR ROTR^18(x) XOR SHR^3(x)

SSIG1(x) = ROTR^17(x) XOR ROTR^19(x) XOR SHR^10(x)
```

## Computing the Message Digest

H(i) can be considered to be eight 32-bit words, H(i)0,
H(i)1, ... H(i)7.

## SHA-224 and SHA-256 Initialization

For SHA-224, the initial hash value, H(0), consists of the following
32-bit words in hex:

```
      H(0)0 = c1059ed8
      H(0)1 = 367cd507
      H(0)2 = 3070dd17
```
